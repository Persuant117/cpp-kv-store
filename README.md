# C++ Key-Value Store

A multithreaded C++ key-value store for learning backend systems, networking, caching, persistence, and benchmarking.

## Goals

- Implement a key-value storage engine in C++
- Support GET, PUT, and DELETE operations
- Add persistence so data survives restarts
- Add networking so clients can communicate with the server
- Add concurrency with a thread pool
- Add LRU caching
- Benchmark performance
